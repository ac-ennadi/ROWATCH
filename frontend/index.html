HOW IT WORKS

From Studio session to dashboard.

One setup step, then the tracking runs alongside normal development.

  1. 1
    Create a project

    Log in, create a RoWatch project, and open its Studio Integration page.

  2. 2
    Connect Roblox Studio

    Paste your username and project key into the RoWatch plugin.

  3. 3
    Work normally

    Start a session. RoWatch records session and script activity while you develop.

  4. 4
    Review progress

    Use Overview, Activity, and Analytics to understand how the project is moving.
