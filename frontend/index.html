Privacy Policy

Effective August 25, 2026

This Privacy Policy explains what RoWatch collects, why it is collected, and the choices available to account holders and project members.

1. Account information

When you create an account, RoWatch collects your username, email address, password hash, consent timestamp and consent-policy version. Passwords are hashed and are not stored in plain text. If you connect Roblox Studio, RoWatch stores only a hash and short display prefix of your account API key.

2. Information collected during Studio sessions

Tracking begins only after you explicitly start a RoWatch session in the Studio plugin. During that active session, RoWatch may record session start/end times and duration, script names and open/close activity, aggregate character counts added or removed, and project objects such as parts or UI components added or removed.

RoWatch does not upload script source code, record keystrokes, or track Studio activity outside an active RoWatch session. Tracking stops when you end the session.

3. Why information is collected

RoWatch uses this information to provide development history, team progress, assigned tasks, activity feeds, and project analytics; authenticate accounts and Studio connections; enforce plan limits; maintain security; and diagnose service problems.

4. Project-scoped analytics

Studio activity is attached to the project selected in the plugin and attributed to the account owning the API key. Project owners, co-admins, and members may see information according to their project role. Requests are checked against current project membership.

5. Data retention

Tracking-history retention follows the project owner’s plan: Free retains up to 7 days, Pro up to 60 days, and Studio may retain history without a fixed plan limit. Account, membership, task, document, billing-code, and security records may remain while needed to provide the service, satisfy operational obligations, or resolve abuse and disputes.

6. Data deletion

Project owners can delete projects from Project Settings. To request deletion of an account or other personal information, contact RoWatch using the address below. Some limited records may be retained where reasonably necessary for security, fraud prevention, legal obligations, or dispute resolution.

7. Security

RoWatch uses hashed passwords, hashed Studio API keys, authenticated project membership checks, restricted session boundaries, and role-based project access. No internet service can guarantee absolute security. Regenerate a Studio API key immediately if you believe it has been exposed.

8. Third-party services

RoWatch may rely on hosting, network, analytics-interface libraries, and Roblox services such as the Creator Store for plugin distribution. Those providers process information under their own terms and policies. RoWatch does not use a Roblox username as Studio authentication.

9. Contact

Questions, privacy requests, and deletion requests can be sent to hello@rowatch.local.
